# MicroEco-KG

淡水系统微生物相互作用知识图谱(Freshwater Microbial Interaction Knowledge Graph)。

基于 **TRAES 五元组本体**(Taxa - Relation - Attribute - Environment - Source)与事件中心型(Event-Centric)拓扑结构,从科学文献中抽取并结构化淡水生态系统中的微生物相互作用事件。

## 仓库内容

| 文件 | 说明 |
| --- | --- |
| `schema_1.json` | 互作事件的 JSON Schema 定义(TRAES 五元组本体) |
| `sample_events.jsonl` | 互作事件样例数据(JSON Lines 格式) |
| `技术报告_2.docx` | 技术报告 |
| `LICENSE` | 数据集采用 CC BY 4.0 协议 |
